# A7R II 功能支持表

测试环境：Sony α7R II（ILCE-7RM2，固件 4.01），vivo X300 Pro（Android 16 / OriginOS 7）。
遥控拍摄和传统 JPEG 传图主流程已实测可用；下表记录各细项当前状态，主流程可用不代表每个子项边界都已单独测完。

| 功能 | 代码状态 | 实机状态 | 备注与限制 |
|---|---|---|---|
| Wi-Fi 绑定 / SSDP / 描述文件读取 | 已实现 | 已测可用 | 先在系统设置连相机 Wi-Fi，可保留移动数据 |
| Smart Remote 版本与能力查询 | 已实现 | 已测可用 | 机内应用版本与机身固件相互独立 |
| 实时取景（Live View） | 已实现 | 已测可用 | Sony 二进制分帧解析，跳过辅助帧信息包 |
| 手机快门拍照与 JPEG 预览回传 | 已实现 | 已测可用（位置写入待实测） | 长曝光支持 `awaitTakePicture`，不盲目重发快门；可在设置开启“为遥控照片添加手机位置”（默认关闭，仅对手机端快门拍照保存到本机的预览 JPEG 且定位 ≤60 秒、精度 ≤100 米时写入位置信息，不修改相机原片，写入后本地文件大小会变化但不影响重复下载识别） |
| 曝光参数（ISO / 光圈 / 快门 / EV） | 已实现 | 早期实测仅开放 EV；切换回拍摄后实测列表含 ISO / 光圈 / 快门，应用内调节待实测 | 按相机动态返回的接口启用，其余只读或禁用 |
| 自动对焦（AF / 半按对焦） | 已实现 | 待单项确认 | 需镜头与机身处于 AF 且接口开放 |
| 录像开始 / 停止 | 已实现 | 待单项确认 | 需相机处于可录像模式且接口开放 |
| 机身实体快门事件回传 | 已实现 | 待单项确认 | 依赖 `getEvent` 返回 `postviewImageUrl` / `imageUrl`（独立机身快门回传不添加手机位置） |
| 间隔拍摄 | 已实现 | 待单项确认 | 需保持应用在前台运行 |
| 遥控同连接相机图库（切模式 / 每页最多 20 个内容项 / JPEG 与 ARW 原图下载 / 返回拍摄） | 已实现 | 原厂协议与 HTTP 下载 ARW 已实测，本应用流程与切回后取景/快门待实测 | 基于描述文件 `avContent`、`getVersions`/`getMethodTypes` 对 `setCameraFunction` 的声明与 `getSupportedCameraFunction` 动态启用（不依赖 `getAvailableApiList` 是否列出 `setCameraFunction`，不按固定机内应用版本限制）；按每页最多 20 个内容项倒序分页读取（单条 RAW+JPEG 内容项展开为 `.JPG` 与 `.ARW` 文件），不支持边实时取景边传输；切回拍摄后恢复 Live View 与快门仅待本应用实测 |
| B 门 / 包围曝光 / 直方图 / 峰值 / LUT | 未实现 | - | 暂未纳入当前版本 |
| 导航与全屏沉浸拍摄界面（含构图线与重力旋转） | 已实现 | 布局与拍摄页旋转待实测 | 未连接隐藏工作区标签（连接后显示“拍摄”或“相机图库”）；拍摄页隐藏系统栏、竖屏紧凑/横屏浮层、原比例取景；默认开启“拍摄页跟随手机旋转”（忽略系统方向锁定随传感器切换横竖屏，退出拍摄页恢复系统方向设置，可在设置关闭） |
| Send to Smartphone 目录与缩略图 | 已实现 | 已测可用 | 支持 `PushRoot` 回退 `PhotoRoot` 及分页零进展报错 |
| JPEG 多选下载与尺寸选择 | 已实现 | 已测可用 | 按相机实际提供的 `res` 下载；ARW 条目仅含 JPEG 预览 |
| 统一相机图库（视图 / 筛选 / 排序 / 全选） | 已实现 | 列表、视图切换与排序已实测可用，部分细项待确认 | 遥控图库、JPEG 与 RAW 模式共用网格/详情列表视图（切换保留选择、筛选、排序与当前浏览位置）；支持按拍摄时间、文件名自然序、文件大小 6 项排序（文件夹置顶：按时间或名称排序时文件夹随所选方向排列，按大小排序时文件夹保持名称升序；无日期或未知大小排末尾） |
| 相机 / 本地图库大图预览与缩放 | 已实现 | 待单项确认 | 左右翻页、双指与双击缩放；相机预览不自动入相册 |
| 相机图库未完成下载 / 取消 / 重连恢复 | 已实现 | 基础下载可用，重连恢复待确认 | 针对相机图库主动选择的文件下载（`Send to Computer` 模式需待整卡扫描完成后才可恢复）；遥控快门自动回传的预览 JPEG（postview）仅限当前连接接收，不显示不适用的图库重选提示，且暂缺手动重试 |
| 本地图库（MediaStore / EXIF / 分享） | 已实现 | 基础导入已测，EXIF / 分享待单项确认 | 保存到 `DCIM/AlphaCompanion` |
| 本地删除文件 / 仅清除导入记录 | 已实现 | 待单项确认 | 删除文件与仅清记录分开操作 |
| 同名 RAW / JPEG 关联 | 已实现 | 待单项确认 | 按同来源、目录和文件主名做轻量归组 |
| USB OTG 登记接收端 GUID | 实验模块 | 已测可用 | 相机设海量存储后通过手机 OTG 写入成功，会替换原电脑接收端 |
| Send to Computer（PTP/IP 会话建立与断开） | 实验模块 | 会话建立已测可用；扫描途中断开后机身保持发送状态致重连失败；空闲断开休眠待测 | 同一局域网下携带已登记 GUID 建立会话；空闲断开默认执行标准会话关闭，扫描/下载在途取消或断开直接强制中止（`0.1.12` 实机已观察到扫描途中断开后机身仍保持旧发送状态并导致后续重连失败，需在机身退出并重新进入“发送到电脑”）；设置提供默认关闭的“断开时让相机休眠（实验性）”（仅空闲手动断开时尝试，实机待测） |
| Sony `0x9280` / `0x9281` 传输开始握手 | 实验模块 | 已测可用 | 设备声明支持时成对执行，实机日志已确认均返回 OK |
| Send to Computer 平铺分批扫描 / 暂停 / 下载优先 | 实验模块 | 整卡扫描与近期照片逆序优先已测可用，暂停/下载优先待测 | 已实测完整扫描 3,001 个对象（2,980 个支持文件）并确认按存储卡返回顺序逆向优先显示近期照片；暂停/继续、扫描中优先下载及任务途中后台/熄屏待实测 |
| Send to Computer 原文件下载（`.ARW` / `.JPG`） | 实验模块 | 单张 JPG / ARW 已保存且长度一致，未做 SHA-256 比对 | 已实测扫描完成后保存 `DSC00027.JPG`（4,259,840 bytes）与 `DSC00027.ARW`（36,700,160 bytes），长度与相机声明一致；当时未计算 PTP/IP 副本 SHA-256，尚未与存储卡原片或 HTTP 下载副本做哈希比对 |
| 固定 APK 签名与 GitHub Actions 构建 | 已配置 | 已验证 | 首次从旧临时签名切换需卸载，之后直接覆盖安装 |
