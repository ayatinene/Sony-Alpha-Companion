# A7R2 支持矩阵

验证对象：ILCE-7RM2 / 固件 4.01；vivo X300 Pro / Android 16 / OriginOS 7。
**首轮设备反馈确认基础遥控与 JPEG 传输可用；具体项目及本版修复的通过情况分别记录，不能用模拟测试替代。**

| 功能 | 代码状态 | A7R2 实机 | 条件 / 限制 |
|---|---|---|---|
| Wi-Fi 网络绑定 / SSDP / 描述文件 | 已实现 | 首轮发现成功 | 先手动连接 Wi-Fi，保留移动数据 |
| Smart Remote 能力与应用版本 | 已实现 | 已获得实际响应 | 固件版本不决定机内 Smart Remote 应用版本 |
| Live View | 已实现 | 基础可用，稳定性待复测 | Sony 分帧解析；帧信息包跳过；有限重连 |
| 拍照与 JPEG 预览接收 | 已实现 | 已有快门和回传 URL 响应，完整文件待校验 | actTakePicture；长曝光 await；不重发不确定的快门请求 |
| ISO / 光圈 / 快门 / EV | 已实现 | 当前 API 列表仅开放 EV 控制 | 仅显示 getAvailable 返回的选项；setter 不可用则禁用 |
| AF / MF | 已实现能力查询与半按 AF | 未验证 | FocusMode 仅在开放时显示；不假定任意镜头支持 |
| 录像开始 / 停止 | 已实现接口 | 未验证 | 需相机处于可录像模式且 API 开放 |
| 机身快门 JPEG 事件 | 已实现 | 未验证 | getEvent 版本协商；须实际返回 postviewImageUrl / imageUrl |
| 间隔拍摄 | 已实现 | 未验证 | 前台运行；间隔是拍完后的等待，不是精确帧起始周期 |
| B 门 / 曝光包围 | 尚未实现 | 未验证 | 后续基于实机能力增加 |
| 构图线 | 已实现 | 不涉及相机协议 | 三分线 |
| 直方图 / 峰值 / LUT / 合成 | 尚未实现 | 未验证 | 不进入首版 |
| Send to Smartphone SOAP | 已实现 | 已有实际描述和 Browse 响应 | 没有假定该模式支持 PTP/IP |
| 目录 / 分页 / 缩略图 | 已实现 | 已枚举目录和照片，多页等边界待测 | PushRoot / PhotoRoot；防止零进展无限分页 |
| JPEG 多选 / 资源尺寸 / 保存 | 已实现 | 有原尺寸资源，部分下载失败待复测 | 选择实际提供的 res；RAW 条目只取 JPEG 预览 |
| 队列 / 进度 / 取消 / 重试 | 已实现 | 手机端未验证 | 前台服务；重试从头开始，进程重启不自动恢复队列 |
| MediaStore / EXIF / 分享 | 已实现 | 导入已有反馈，其余待逐项确认 | 待 OriginOS 实测；共享原文件 URI |
| RAW/JPEG 配对 | 已实现基础版本 | 手机端未验证 | 同名主干、忽略大小写；跨日期重用编号可能误配 |
| Send to Computer SSDP / 会话 | 已实现实验模块 | 未验证 | 需有效且已登记的 GUID；可填相机局域网 IP |
| PTP/IP 对象 / ARW/JPEG 原文件 | 已实现实验模块 | 未验证 | 流式输出，检查传输长度；未宣称续传 |
| Sony 0x9280 / 0x9281 开始配对命令 | 已实现 | 未验证 | 仅设备声明支持两个操作时执行；未发送未知结束/关机命令 |
| USB OTG GUID 注册 | 尚未实现 | 未验证 | 先通过已有电脑工具登记，不用随机 GUID |
| GitHub Actions | 已配置 | 不涉及相机实测 | 构建、测试、lint 与 APK 产物，运行结果见 Actions |

新版本新增导出/断开关闭路径、HTTP 文件重试和导入记录管理；这些修复尚待设备复测。合成测试、模拟 HTTP 和文件结构检查单独记录。
