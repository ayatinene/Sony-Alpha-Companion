# A7R II 功能支持表

测试环境：Sony α7R II（ILCE-7RM2，固件 4.01），vivo X300 Pro（Android 16 / OriginOS 7）。
遥控拍摄和传统 JPEG 传图主流程已实测可用；下表记录各细项当前状态，主流程可用不代表每个子项边界都已单独测完。

| 功能 | 代码状态 | 实机状态 | 备注与限制 |
|---|---|---|---|
| Wi-Fi 绑定 / SSDP / 描述文件读取 | 已实现 | 已测可用 | 先在系统设置连相机 Wi-Fi，可保留移动数据 |
| Smart Remote 版本与能力查询 | 已实现 | 已测可用 | 机内应用版本与机身固件相互独立 |
| 实时取景（Live View） | 已实现 | 已测可用 | Sony 二进制分帧解析，跳过辅助帧信息包 |
| 手机快门拍照与 JPEG 预览回传 | 已实现 | 已测可用 | 长曝光支持 `awaitTakePicture`，不盲目重发快门 |
| 曝光参数（ISO / 光圈 / 快门 / EV） | 已实现 | 当前测试机 API 1.0 仅开放 EV | 只启用 `getAvailable*` 开放的项，其余只读或禁用 |
| 自动对焦（AF / 半按对焦） | 已实现 | 待单项确认 | 需镜头与机身处于 AF 且接口开放 |
| 录像开始 / 停止 | 已实现 | 当前测试机 API 未开放 | 需相机处于可录像模式且接口开放 |
| 机身实体快门事件回传 | 已实现 | 待单项确认 | 依赖 `getEvent` 返回 `postviewImageUrl` / `imageUrl` |
| 间隔拍摄 | 已实现 | 待单项确认 | 需保持应用在前台运行 |
| B 门 / 包围曝光 / 直方图 / 峰值 / LUT | 未实现 | - | 暂未纳入当前版本 |
| 导航与全屏沉浸拍摄界面（含构图线） | 已实现 | 0.1.9 新布局待测 | 未连接隐藏工作区标签（连接后显示“拍摄”或“相机图库”）；拍摄页隐藏系统栏、竖屏紧凑/横屏浮层、原比例取景 |
| Send to Smartphone 目录与缩略图 | 已实现 | 已测可用 | 支持 `PushRoot` 回退 `PhotoRoot` 及分页零进展报错 |
| JPEG 多选下载与尺寸选择 | 已实现 | 已测可用 | 按相机实际提供的 `res` 下载；ARW 条目仅含 JPEG 预览 |
| 相机 / 本地图库大图预览与缩放 | 已实现 | 待单项确认 | 左右翻页、双指与双击缩放；相机预览不自动入相册 |
| 相机图库导入队列 / 取消 / 重连恢复 | 已实现 | 基础下载可用，重连恢复待确认 | 按相机标识和模式保存图库导入队列，重连核对后从头下载；遥控回传暂缺手动重试 |
| 本地图库（MediaStore / EXIF / 分享） | 已实现 | 基础导入已测，EXIF / 分享待单项确认 | 保存到 `DCIM/AlphaCompanion` |
| 本地删除文件 / 仅清除导入记录 | 已实现 | 待单项确认 | 删除文件与仅清记录分开操作 |
| 同名 RAW / JPEG 关联 | 已实现 | 待单项确认 | 按同来源、目录和文件主名做轻量归组 |
| Send to Computer（PTP/IP 原文件传输） | 实验模块 | 待实测 | 需同一局域网及已登记的接收端 GUID |
| Sony `0x9280` / `0x9281` 传输开始握手 | 实验模块 | 待实测 | 仅在设备声明支持这两个操作码时执行 |
| USB OTG 登记接收端 GUID | 实验模块 | 待实测 | 相机设海量存储后通过 OTG 写入，会替换原电脑接收端 |
| 固定 APK 签名与 GitHub Actions 构建 | 已配置 | 已验证 | 首次从旧临时签名切换需卸载，之后直接覆盖安装 |
