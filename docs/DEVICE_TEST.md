# A7R II 实机操作与测试说明

## 1. 准备工作

1. 从 GitHub Actions 下载并安装 `Alpha-Companion-Debug-APK`。如果手机上装过早期临时签名版本，第一次换到固定签名包需要先卸载旧版（见 [SIGNING.md](SIGNING.md)）。
2. 在应用首页点击“附近设备与通知权限”（Android 13 及以上会请求附近 Wi-Fi 设备 `NEARBY_WIFI_DEVICES` 与通知 `POST_NOTIFICATIONS` 权限），允许相关权限。
3. 关掉手机上其他正在连相机的客户端（如 Imaging Edge Mobile）以及 VPN / 代理。
4. 在系统 Wi-Fi 设置里连接相机网络；系统弹出“当前 WLAN 无互联网访问”时选保持连接（移动数据不用关）。
5. 常规测试保持应用设置里的自定义地址、IP 和 GUID 为空，直接用自动发现。

## 2. 页面导航与遥控拍摄（Smart Remote Control）

1. 未连接相机时，底部导航栏只显示“首页”“本地”“设置”。
2. 在相机上打开 `Smart Remote Control`，手机 Wi-Fi 连上相机显示的 SSID，然后在应用首页点“遥控拍摄”连接：
   - 连接成功后会自动进入全屏遥控拍摄界面；如果连接等待期间手动切到了“本地”或“设置”页，连接完成后不会强行跳走。
   - 在遥控拍摄界面点左上角返回箭头可退回常规页面，相机连接保持不断开；此时底栏会出现“拍摄”标签，或在首页点已连接模式的主按钮也能直接回到拍摄界面，不会重复发起重连。
3. 全屏沉浸取景与横竖屏切换：
   - 进入遥控拍摄后系统状态栏和导航栏会自动隐藏，从屏幕边缘向内滑动可临时唤出系统栏。
   - 观察实时取景是否保持原始长宽比完整显示、不被裁切；旋转手机切换竖屏紧凑布局与横屏悬浮控制层，或切到桌面再返回，检查画面与操作能否正常恢复。
4. 点一次应用快门拍照，确认机身正常拍一张，并且预览 JPEG 自动存进应用“本地”和系统相册。遥控回传的是预览图（postview），完整原片或 RAW 仍按机身设置留在存储卡上。
5. 按一次机身实体快门，看应用状态和预览图回传是否同步。
6. 查看并调节当前开放的曝光参数。可调项取决于机内 Smart Remote 应用版本（例如当前测试机返回 API 1.0，曝光参数只开放了 EV，未开放 ISO、光圈、快门速度和录像控制，未开放项只显示读数）。
7. 如果镜头和机身在 AF 模式、或机内接口开放了录像，可顺带试一下对焦、录像和间隔拍摄（间隔拍摄需要停留在前台）。

## 3. JPEG 传输（Send to Smartphone）

1. 先断开遥控连接，机身退出 Smart Remote，进入“发送到智能手机”（可选“在智能手机上选择”或在机身上先勾选照片）。
2. 确认手机连着相机 Wi-Fi，在应用首页点“JPEG 传输”连接，连接成功后自动进入相机图库（在首页点已连接主按钮或底栏“相机图库”标签也可回到图库）。
3. 目录、视图切换、排序与大图预览：
   - 查看日期文件夹和缩略图，点进子文件夹后再点顶部返回根目录；可切换网格视图与详情列表视图（切换后保留已选文件、筛选、排序与当前浏览位置），点排序按钮可按拍摄时间（最新/最早）、文件名（升序/降序）或文件大小（从小到大/从大到小）排序（文件夹排在前面，无日期或未知大小排在末尾）。
   - 点开照片看大图，试试左右翻页、双指缩放和双击放大。大图预览只放临时缓存，点下载才会存进系统相册。
4. 尺寸选择与下载：
   - 在顶部尺寸选择或照片信息里看相机实际提供的资源（原尺寸 / 大图 / 小图 / 缩略图），单张、长按多选或点“全选”下载几张。
   - 这个模式下 `.ARW` 条目只由相机提供内嵌 JPEG 预览，没法直接拉取原始 ARW。
5. 取消与重试 / 队列恢复：
   - 多选下载中途点取消，确认未完成项不会标成已导入。
   - 断开重连同一台相机后点“继续未完成”，应用会核对当前相机目录并从头重新下载（不支持字节级断点续传；队列恢复仅针对相机图库导入）。
6. 本地图库管理：
   - 到“本地”页看已保存照片的分辨率和 EXIF。
   - 分别试试“清除导入记录（保留文件）”和“删除照片文件”，确认清掉记录或删掉文件后可以重新从相机下载。

## 4. RAW / 原文件传输（Send to Computer，实验性）

这个模式走局域网 PTP/IP，能下载存储卡里的原始 `.ARW` 和 `.JPG`。相机和手机必须连在同一个路由器或局域网热点下，并且相机里已经登记了接收端 GUID。

注意：**向相机登记新 GUID 会替换相机原先绑定的电脑接收端**。如果平时还用电脑无线导图，建议直接填电脑已登记的 GUID，或者先备份原配置。

### 方式一：用应用里的 USB OTG 工具登记（实验性）
1. 相机菜单里把“USB 连接”设成“海量存储（Mass Storage）”，用带数据功能的 OTG 线连手机。
2. 打开应用“设置 → USB OTG 登记接收端”，核对识别出的 USB 型号和 VID/PID。
3. GUID 留空会自动生成新值（也能填已有值）。确认登记并允许系统 USB 权限，看到“已登记”后拔掉 USB 线，GUID 会自动保存在设置里。

### 方式二：直接填电脑已登记的 GUID
1. 如果电脑上装过 PlayMemories Home，或者用过 [sony-guid-setter](https://github.com/FireFoxG/sony-guid-setter)、`sony-pm-alt` 登记过，把那串 16 字节 GUID 填进应用设置保存即可。
2. 测试前先退出电脑上的 Sony 自动导入程序，免得被电脑抢先连上。

### 连接、分批扫描与核对原文件
1. 手机和相机连入同一个局域网 Wi-Fi（如果路由器开了隔离导致自动发现不到，可以在设置里填相机的局域网 IP）。
2. 机身进入“发送到电脑”，应用首页点“RAW / 原文件”连接：
   - PTP/IP 会话建立后会直接进入相机图库并开始后台串行扫描，不需要等整张存储卡读完。
   - 顶部扫描栏会显示“已检查 X/Y 项，发现 Z 个文件”。应用按存储卡返回顺序从后往前读取以优先呈现近期照片，扫描到的 `.ARW` 和 `.JPG` 以平铺列表分批追加显示；追加时保持当前浏览位置，主动切换筛选或排序时回到列表顶部。
3. 视图、筛选、暂停与优先下载：
   - 扫描过程中可切换网格/详情列表视图（切换后保留已选、筛选、排序与当前浏览位置）、切换 `全部 / JPEG / ARW` 筛选、切换 6 种排序、查看相机缩略预览，或长按多选、“全选 N”当前可见文件（被筛选条件隐藏的已选项会提示不参与本次下载）。
   - 可随时点“暂停查找 / 继续查找”。直接下载已选文件时，扫描会在当前对象事务完成后自动让位暂停，待下载结束后继续（若下载前已手动暂停，下载完成后仍保持暂停）。
   - 若存在上次未完成的历史导入队列，“继续未完成”按钮会在整卡扫描完成后启用，避免扫描未完时误判文件缺失。
4. 后台运行与通知测试：
   - 扫描或下载进行期间会启动前台服务并显示通知（可点通知返回应用或直接取消任务）；若系统拒绝后台服务启动，界面会提示保持在前台完成操作。测试后台/熄屏稳定性时，请在**扫描或下载仍在进行中**切到桌面或锁屏观察。
5. 原文件下载与哈希核对：先下载一张 `.JPG`，再下载一张 `.ARW`。若需核对文件与存储卡原件完全一致，可在电脑上比对文件大小和 SHA-256：

```powershell
Get-FileHash .\DSC00001.JPG -Algorithm SHA256
Get-FileHash .\DSC00001.ARW -Algorithm SHA256
```

6. 断开、中断与实验性休眠：
   - 正常空闲时点断开会执行标准会话关闭；在扫描或下载进行中取消、断开或遇到网络中断时，会直接强制中止当前 PTP 会话。若重连提示“相机仍保持上次会话”或“相机忙”，需要在相机上退出并重新进入“发送到电脑”后再连接。
   - 如需测试“设置 → RAW / 原文件传输（实验性） → 断开时让相机休眠（实验性）”（默认关闭）：开启后，在原文件连接处于空闲状态（非扫描/下载进行中）时手动点断开，观察相机是否退出“发送到电脑”并休眠；再次连接可能仍需在机身重新操作。自动重连、扫描/下载途中取消或异常断网不会触发该休眠动作。

## 5. 导出日志与抓包

遇到连接失败、下载报错或闪退时，到“设置 → 导出日志与诊断”导出带时间戳的 ZIP（详见 [LOGGING.md](LOGGING.md)）。

只有日志不够定位协议问题时才需要电脑抓包：无线侧用 Wireshark 过滤 `udp.port == 1900 || tcp.port == 15740 || http`；USB 登记问题需要用 USBPcap 抓 USB 报文。
