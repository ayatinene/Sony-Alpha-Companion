# A7R II 实机测试与操作指南

适用预览版：`0.1.2-preview`。首轮目标：ILCE-7RM2 固件 4.01，vivo X300 Pro / Android 16 / OriginOS 7。

已有基础遥控和 JPEG 传输反馈，本版修复仍需设备复测。相机固件与机内 Smart Remote 应用版本分别记录；连接后可在设置查看接口返回的机内应用信息。

## 本版优先复测

1. 遥控已连接且有取景画面时，连续导出两次日志诊断包，确认不闪退、文件名不同，返回应用后取景可恢复。
2. 遥控已连接时点击右上角结束连接，再重新连接；JPEG 模式也测试结束连接。确认均不闪退。
3. 重新下载此前失败的 JPEG，观察自动重试结果，导出包含队列错误的新诊断。若仍失败，先回传诊断；再决定是否需要抓包。
4. 在系统图库删除或移入回收站一张已导入照片，再返回应用刷新，确认失效记录消失，且能重新下载。
5. 对另一张照片选择“移除导入记录”，确认手机文件仍在、记录消失，之后可重新导入。
6. 切换四个底栏页面，确认“相机”页保持当前连接，不会因切换到本地或设置重新连接；未连接时可在相机页直接选择模式。

若仍发生闪退，重新打开应用，在未连接相机时导出诊断。新版本会把最近一次应用崩溃堆栈附入 ZIP。排查问题先保持 DEBUG；需要协议正文时，在复现前改为 TRACE。

## 1. 准备

1. 安装成功构建中的 Debug APK，应用名称为 Alpha Companion，记录 Actions 运行编号或构建提交号。
2. 关闭其他正在连接相机的手机客户端。若手机开启 VPN 或代理，首轮先关闭以排除路由干扰。
3. 应用首页点击“附近设备与通知权限”，允许相关权限。
4. 在系统 Wi-Fi 设置中连接相机网络；出现“无互联网”提示时选择保持连接。移动数据可以保留。
5. 首轮保持应用设置中的地址、IP 和 GUID 为空，先测试自动发现。

若无法安装、启动或连接，记录完整错误和截图；能打开设置时导出诊断，再暂停当前步骤。无需反复点快门或猜测地址。

## 2. 遥控拍摄：第一轮必测

1. 启动机内 Smart Remote 应用；连接后在本应用设置查看机内应用信息，或从导出的 getApplicationInfo 响应读取名称和版本。首轮已经获得版本信息，无需重复查找。
2. 手机连接其显示的 Wi-Fi，在 Alpha Companion 首页点“遥控拍摄”卡片中的“连接”。
3. 确认型号、实时画面和拍摄参数是否出现；观察约 30 秒是否卡顿、断流或画面方向错误。
4. 手机点一次快门：确认机身只拍一张，JPEG 随后出现在应用“本地”和系统图库。遥控回传的是预览，尺寸可小于存储卡原件。
5. 机身使用合适拍摄模式（例如 M 档测试 ISO、快门和光圈；A 档测试 EV），逐项调整应用中可用的 ISO、快门、光圈和曝光补偿，记录机身是否同步变化。灰色或缺失项记录为“不可用”。
6. 镜头和机身处于 AF 状态时点击 AF，观察是否实际对焦；记录镜头型号。
7. 再按机身实体快门拍一张，检查应用是否同步状态并自动收到 JPEG。
8. 录像按钮可用时，录约 5 秒后停止，确认机身录像确实开始/结束，应用状态同步；不可用时直接记录。
9. 旋转手机，再切到桌面约 10 秒后返回，检查画面和操作能否恢复。
10. **切换相机模式前**，设置 →“导出日志与诊断”，ZIP 文件名会包含 remote 与时间戳。失败时同样导出，并附错误截图。

可选：基础拍照通过后再试 3 张、5 秒间隔和手动停止。间隔拍摄需保持应用前台。

## 3. JPEG 传输：第一轮必测

1. 应用结束连接，相机退出 Smart Remote，再进入“发送到智能手机”。若相机提供“在智能手机上选择”，首轮选择它。
2. 重新检查手机连接的相机 Wi-Fi。应用首页点“JPEG 传输”中的“连接”，进入“相机图库”。
3. 检查文件夹/日期目录、文件名、缩略图和排序；进入一个文件夹再返回。
4. 保持“最大可用”，先下载一张 JPEG。在“本地”打开详情，记录文件大小、尺寸和 EXIF，确认系统图库能打开。
5. 卡上若仍有 `DSC02104.JPG`，优先用它；当前已收到其原尺寸样本，无需再上传存储卡原件。若测试另一张，记录文件名并以该张原件作比较。
6. 多选 3 张下载，观察队列与完成状态。传输期间切到桌面，观察通知，再回应用确认文件完整。
7. 基础传输通过后，另启动一次下载并取消，检查它不被标为完成，再点“重试失败”。本版重试从头下载。
8. 如果出现“小图”或“缩略图”选项，再测试一次，记录每种实际尺寸。
9. 切换模式或结束连接前，导出含 jpeg 与时间戳的日志诊断 ZIP。
10. 可选：另在相机上先选 2–3 张照片再发送，检查应用只显示相机选择的范围，并另导出 带时间戳的 JPEG 模式 ZIP。
11. 最后点击应用“结束连接”，观察相机是否结束当前传输状态。

“最大可用”仅表示选择该服务提供的最大资源，并不保证 Send to Smartphone 必定提供存储卡原件。ARW 条目可能仅返回 JPEG 预览。

## 4. 回传信息

首轮集中提供：

- 实际安装的 Actions 运行编号或构建提交号；机内 Smart Remote 名称、版本，以及测试镜头型号。
- `AlphaCompanion-remote-时间戳.zip` 与 `AlphaCompanion-jpeg-时间戳.zip`。两种模式分别测试、分别导出 ZIP；连接失败时也导出，无需手动解包。
- 每项“通过 / 失败 / 不可用 / 未测”的简短结果。失败附操作步骤、屏幕原文和截图；若闪退，描述最后一步，能复现时录屏。
- 从本应用实际下载得到的一张 JPEG，**打成 ZIP 上传**，用于检查文件和 EXIF 是否保留。它应与已提供原件对应；遥控预览与 JPEG 传输文件分开标注。
- 如准备继续测 RAW，先说明电脑接收端是否登记、GUID 是否已知；未知时先暂停 RAW。

可直接填写：

```text
构建：
Smart Remote 名称/版本：
镜头：
遥控连接/实时取景：
手机快门/回传 JPEG：
ISO/快门/光圈/EV：
AF/录像/机身快门回传：
旋转屏幕/返回前台：
JPEG 目录/缩略图：
单张下载（文件名、大小、尺寸）：
批量/后台/取消重试：
结束连接：
错误或其他现象：
```

诊断 ZIP 包含分级日志及结构化 JSON。JSON 包含设备信息、相机能力、最近协议响应和错误日志，可能包含文件名、局域网 IP 或媒体 URL；应用不主动导出照片字节、Wi-Fi 密码或 GUID。通过当前对话回传即可。首轮无需抓包。

## 5. RAW / Send to Computer：第二轮，实验性

前置：已通过 USB 将接收端 GUID 登记到相机，且明确其值。手机与相机连接同一路由器/AP。

已有 PlayMemories Home 登记时使用同一接收端 GUID；尚未登记时，可参考 [sony-guid-setter](https://github.com/FireFoxG/sony-guid-setter) 或 sony-pm-alt 的电脑工具。登记会改变相机接收端，应先保留原配置。本版没有 Android USB OTG 登记功能。

1. 设置中填入已登记 GUID，保存。相机局域网 IP 可先留空自动发现；发现失败后使用路由器中确认的相机地址。
2. 退出电脑上的 Sony 自动导入程序，避免抢占连接。
3. 相机进入“发送到电脑”，手机首页连接“RAW / 原文件”。
4. 先枚举并下载一个 JPEG，再下载一张 ARW，记录各阶段成功或失败。
5. 下载文件与存储卡同一原件比较字节大小和 SHA-256。Windows PowerShell：

```powershell
Get-FileHash .\DSC02104.JPG -Algorithm SHA256
Get-FileHash .\DSC02104.ARW -Algorithm SHA256
```

只有下载的是同一张照片的原始文件，才应要求大小和 SHA-256 完全一致。JPEG 预览不能用作原始 ARW。

6. 导出 带时间戳的 COMPUTER 模式 ZIP，记录登记方法及发现、连接、枚举、下载分别在哪一步通过或失败。
7. 取消或断开后，重连可能需要在机身退出并重新进入“发送到电脑”。

## 6. 后续诊断需要抓包时

仅在应用诊断不足后再确定所需抓包范围。Windows 官方传输对照可使用 Wireshark + Npcap，选择实际 Wi-Fi 网卡，从机身进入 Send to Computer 前开始，直到一张 JPEG 和一张 ARW 导入完成或失败后停止。

显示过滤器：

```text
udp.port == 1900 || tcp.port == 15740 || http
```

记录相机与电脑 IP，另存为 pcapng。USB 登记则需要单独的 USBPcap 捕获，不能用普通 Wi-Fi 数据推断其注册序列。
