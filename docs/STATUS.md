# 版本状态与限制

当前版本：`0.1.10-preview`（`versionCode 11`）。
适用环境：Sony α7R II（ILCE-7RM2，固件 4.01），Android 10 及以上。

## 测试状态

- 自动化测试与构建：
  - `0.1.10-preview`（`versionCode 11`）的 JVM 单元测试、Android 运行时测试、Android Lint 与固定签名 APK 构建尚待验证。
- 实机测试：
  - 遥控拍摄与传统 JPEG 传图（Send to Smartphone）主流程已在 α7R II 上实测可用，无明显问题（属总体测试结果，不代表每个子项边界已逐一覆盖）。
  - 当前测试机返回的 Smart Remote 接口为 API 1.0，曝光参数仅开放 EV，未开放 ISO、光圈、快门速度和录像控制。
  - 手机 USB OTG 登记接收端 GUID 已在 α7R II 上实测成功。
  - RAW / 原文件传输（Send to Computer）已实测建立首次 PTP/IP 会话，并在约 2000–5000 个文件的存储卡上扫描计数推进至 1000+ 个 `.ARW` / `.JPG` 文件，随后在手机熄屏附近连接中断；Sony `0x9280` / `0x9281` 开始握手是否执行尚未有日志证实，`.ARW` / `.JPG` 原文件下载及 SHA-256 哈希比对尚未实测。
  - `0.1.10-preview` 更新的 RAW 连接即进图库、平铺分批扫描、暂停/继续与下载优先、扫描/下载后台前台服务通知以及 JPEG/RAW 统一相机图库交互待实机测试。

## 已知限制

- 遥控能调哪些参数取决于机内 Smart Remote 版本和当前机身档位，未开放的接口手机端只能显示读数或禁用。
- RAW 传输属于实验功能。向相机登记新 GUID 会覆盖相机原本绑定的电脑接收端；RAW 模式采用单会话单事务串行调度（不支持多请求并发或字节断点续传），取消下载、取消后台任务或异常断开会终止当前 PTP 会话。若重连提示“相机仍保持上次会话”或“相机忙”，需要在机身上退出并重进“发送到电脑”。
- 相机文件扫描与下载期间会通过前台服务与通知维持后台运行，但手机系统的后台/省电限制或熄屏 Wi-Fi 策略仍可能影响长连接，熄屏稳定性待实测，不能保证绕过所有厂商限制。
- 未完成队列的保存和重连恢复针对相机图库文件导入（需重新核对文件列表后从头下载，不支持字节断点续传；RAW 模式必须在整卡扫描完成后才可恢复历史队列）；遥控拍照回传预览图暂不支持在界面手动重试恢复，相机身份不明时也不会自动关联旧队列。
- 相机图库和本地图库里的 `.ARW` 只显示缩略预览或同目录同名 JPEG，应用内没有内置 RAW 解码器。
- 间隔拍摄需要应用保持在前台，后台前台服务仅负责相机图库扫描与文件下载。
- B 门、包围曝光、直方图、峰值对焦和 LUT 还没做。

各功能细项见 [SUPPORT.md](SUPPORT.md)，实机操作方法见 [DEVICE_TEST.md](DEVICE_TEST.md)。
