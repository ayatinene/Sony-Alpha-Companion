# 版本状态与限制

当前版本：`0.1.13-preview`（`versionCode 14`）。
适用环境：Sony α7R II（ILCE-7RM2，固件 4.01），Android 10 及以上。

## 测试状态

- 自动化测试与构建：
  - JVM 单元测试：280 项通过（38 个套件，0 失败 / 错误 / 跳过）。
  - Android 运行时测试：89 项通过（0 失败 / 错误 / 跳过）。
  - Android Lint：0 错误、38 警告；固定签名 APK 构建与证书指纹校验通过。
- 实机测试：
  - 遥控拍摄与传统 JPEG 传图（Send to Smartphone）主流程已在 α7R II 上实测可用，无明显问题（属总体测试结果，不代表每个子项边界已逐一覆盖）。
  - 当前测试机返回的 Smart Remote 接口为 API 1.0，曝光参数仅开放 EV，未开放 ISO、光圈、快门速度和录像控制。
  - 手机 USB OTG 登记接收端 GUID 已在 α7R II 上实测成功。
  - RAW / 原文件传输（Send to Computer）已在 `0.1.10-preview` 与 `0.1.11-preview` 实机验证：Sony `0x9280` / `0x9281` 开始握手均返回 OK；在 3,001 个对象的存储卡上完整扫描并识别 2,980 个支持文件；扫描完成后下载 `DSC00027.JPG`（4,259,840 bytes）和 `DSC00027.ARW`（36,700,160 bytes）均保存成功，落盘长度与相机声明一致（尚未与存储卡原片做 SHA-256 比对）；`0.1.11-preview` 的优先查找近期照片、相机图库网格/详情列表视图切换与排序已实机确认可用（不代表所有筛选/排序子项边界均已穷尽覆盖）。首次连接曾遇 10 秒初始化超时并在重试后恢复，不能宣称所有异常恢复场景均已解决；暂停/继续、扫描途中的优先下载，以及扫描或下载进行中的后台/熄屏场景尚未实测覆盖。
  - `0.1.12-preview` 实机已观察到具体的断开恢复问题：在 RAW 扫描进行途中由手机主动断开连接后（该次未开启“断开时让相机休眠（实验性）”开关，扫描在途断开直接强制中止底层连接，未执行 `CloseSession` 或休眠命令），相机机身仍保持在旧的发送状态，导致之后再次重连失败。技术上虽无法仅凭手机端超时日志分辨相机内部 PTP 会话是否已释放，但机身保持发送状态并阻碍后续重连属已确认的实机现象（当前版本尚未修复该在途断开恢复问题，也不要求强制开启实验性休眠开关）。连接正常空闲时的手动断开收尾及“断开时让相机休眠（实验性）”开关仍待实机验证。
  - `0.1.13-preview` 新增或调整的 JPEG 日期文件夹按所选排序方向排列、连接入口按需通知权限检查、拍摄页跟随手机旋转（默认开启，即使系统锁定方向仍随手机切换横竖屏，退出拍摄页后恢复系统方向设置）以及为遥控照片添加手机位置（默认关闭）待实机验证。

## 已知限制

- 遥控能调哪些参数取决于机内 Smart Remote 版本和当前机身档位，未开放的接口手机端只能显示读数或禁用。
- “为遥控照片添加手机位置”默认关闭，仅在设置中主动开启时申请前台位置权限（不申请后台定位或媒体位置权限），仅用于手机端快门触发的遥控拍摄保存到手机的预览 JPEG（独立按机身实体快门回传的照片不添加手机位置），不修改相机原片，也不会修改 JPEG / RAW 图库传输下载的文件。仅当拍摄时刻手机定位时间在 60 秒以内且精度不超过 100 米时才写入 EXIF 位置信息；定位不可用或不准确时不添加，不影响拍照。写入位置信息后手机本地文件大小会略有变化（不影响已下载照片识别），分享照片时也会携带位置信息。
- RAW 传输属于实验功能。向相机登记新 GUID 会覆盖相机原本绑定的电脑接收端；RAW 模式采用单会话单事务串行调度（不支持多请求并发或字节断点续传），按存储卡返回顺序从后往前读取以优先呈现近期照片（但不保证所有存储卡严格按新到旧排列）。正常健康的空闲会话在断开、自动重连或切换模式时默认执行标准会话关闭（自动重连与切换模式不尝试相机休眠），而在扫描/下载进行中取消或断开、网络断开或在途事务状态不确定时则会直接强制中止当前连接（不发送 `CloseSession` 或休眠命令）。实机已观察到扫描途中由手机主动断开后机身仍保持旧的发送状态、随后重连失败；遇到此类情况或重连提示“相机仍保持上次会话”“相机忙”时，需要在机身上退出并重进“发送到电脑”。设置中提供默认关闭的“断开时让相机休眠（实验性）”选项，仅在原文件连接正常空闲、相机支持相关协议指令且手动点击断开时尝试让相机退出“发送到电脑”并休眠（扫描/下载在途断开不会触发，且不要求强制开启），其效果与副作用仍待实机确认。
- 相机文件扫描与下载期间会通过前台服务与通知维持后台运行，但手机系统的后台/省电限制或熄屏 Wi-Fi 策略仍可能影响长连接，扫描/下载途中的后台与熄屏稳定性待实测，不能保证绕过所有厂商限制。
- 未完成下载任务的保存、身份保护提示和重连恢复仅针对相机图库文件导入（JPEG 与 RAW 模式，需重新核对文件列表后从头下载，不支持字节断点续传；RAW 模式必须在整卡扫描完成后才可恢复未完成项）。遥控拍摄仅在当前连接内接收拍照回传的预览 JPEG，不再显示不适用的“重连后需重新选择下载文件”等相机图库提示；遥控拍照回传预览图暂不支持在界面手动重试恢复。
- 相机图库和本地图库里的 `.ARW` 只显示缩略预览或同目录同名 JPEG，应用内没有内置 RAW 解码器。
- 间隔拍摄需要应用保持在前台，后台前台服务仅负责相机图库扫描与文件下载。
- B 门、包围曝光、直方图、峰值对焦和 LUT 还没做。

各功能细项见 [SUPPORT.md](SUPPORT.md)，实机操作方法见 [DEVICE_TEST.md](DEVICE_TEST.md)。
