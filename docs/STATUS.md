# 版本状态与已知问题

版本：`0.1.8-preview`。目标设备：Sony α7R II（ILCE-7RM2），固件 4.01；Android 10 及以上。

## JPEG 连接闪退修复

设备崩溃堆栈确认：`0.1.7-preview` 在读取相机目录时，JPEG 资源辅助类的正则初始化抛出 `PatternSyntaxException`，进而触发 `ExceptionInInitializerError` 并终止进程。

本版移除该正则，直接按协议字段的冒号和分号分隔解析。Android 运行时回归测试新增资源分类、PushRoot 到 PhotoRoot 的回退，以及目录 / JPEG 资源解析，覆盖此次崩溃路径。

## 本轮图库、队列与拍摄界面

- 固定 APK 签名已经配置并通过证书校验，Debug / Release 使用同一密钥。签名备份由用户保存，仓库只包含公开证书指纹。
- 描述文件读取 UDN / 序列号，PTP 读取设备序列号；不同相机和模式分别持久保存下载队列。身份不明确时，本次连接单独保存，不自动恢复历史任务。
- 重启或重连后点击“继续未完成”，重新读取原目录并核对文件 ID、名称、目录、时间及资源大小，再使用当前返回的 URL。信息不匹配时要求从图库重新选择；不沿用旧地址或仅凭文件编号续传。
- 相机图库点图预览、左右翻页、双指缩放、双击放大，长按多选。预览临时缓存且限制容量，不进入 MediaStore；显式下载才正式保存。
- PTP 模式 ARW 使用相机缩略预览；本地 ARW 优先使用同目录同名 JPEG，其次内嵌预览。没有加入 RAW 解码引擎。
- 本地图库增加网格、大图查看器、排序、分享、EXIF、永久删除文件和仅清除记录两个独立操作。
- RAW/JPEG 按来源、目录及文件主名轻量识别，一次建立索引；不逐张读取 EXIF 做复杂匹配。
- 遥控页采用深色拍摄界面，按窗口尺寸适配。横屏曝光参数在左、取景居中、快门 / AF / 录像在右；竖屏参数横排。取景保持原比例，构图线跟随实际画面。

## 上版遥控与 USB 初始化

- 读取设备实际声明的 DigitalImaging 描述，显示机身固件、镜头及机内应用列表；首页相机型号优先使用真实型号。
- 补齐 API 1.0 `takePictureUrl` 数组，以及连拍／B 门事件内的 `postviewUrl`；事件返回的 JPEG 可进入下载队列。
- 取景读取结束后调用已开放的 `stopLiveview`，用于后台暂停、退出与重连的会话释放。
- 新增实验性 Android USB OTG 接收端登记：Sony Mass Storage 接口发现、系统 USB 授权、8192 字节 GUID 报文与 CSW 状态处理；相机接受命令后才保存供 PTP/IP 使用的 GUID。
- USB 登记入口会说明接收端替换及连接步骤。协议和报文测试由 CI 执行，USB 与 RAW 传输等待实机测试。

## 图库资源改进

- 按 ContentDirectory 实际资源区分原尺寸 JPEG、大图、小图和缩略图；原尺寸缺少分辨率字段时仍可正确选择。
- 批量下载前提示缺少所选尺寸的照片，避免提交空资源到队列。
- 相机图库增加照片信息，显示日期、各 JPEG 资源的尺寸与大小。
- 设置页面使用实际构建版本号。

## JPEG 连接修复

- 设备日志确认 0.1.1–0.1.2 存在回归：相机广播的 `dd.xml` 提供可用 ContentDirectory，但程序改选补充 `DmsDescPush.xml`，调用其未启用的 XPushList 返回 HTTP 404，导致浏览前退出。
- 恢复优先使用 SSDP 实际广播的服务；只有发现不到匹配服务时才探测旧版备用描述文件。
- 可选 X_TransferStart 明确返回不支持（HTTP 404/405/501 或 UPnP Invalid Action）时继续浏览；认证失败、其他 SOAP 错误及网络故障仍保留错误。未启动握手时不发送 X_TransferEnd。
- 增加设备描述选择与握手兼容回归测试，保留正常握手起止和分页测试。本版仍需 A7R II 复测，日志中的 404 不等同于进程崩溃。

## 日志功能

- 增加 TRACE / DEBUG / INFO / WARN / ERROR 五级记录，默认 DEBUG，可在设置调整。
- 记录时间、线程、运行会话、相机模式、HTTP/RPC 请求标识、状态、耗时、传输字节、重试与异常堆栈；取景统计和下载进度节流记录，不按每一帧刷日志。
- 日志后台写入并跨进程保留，512 KiB 一段、两份备份，总量约 1.5 MiB；缓冲溢出或写入失败会在诊断统计中体现。
- 一键导出带时间戳的 ZIP，包含可读日志、结构化诊断 JSON，以及存在时的最近崩溃堆栈。文本记录有限长，不包含照片或取景帧字节。
- 详细用法见 [LOGGING.md](LOGGING.md)。

## 上版连接与导入修复

- 取景流和下载取消使用网络请求取消，由读取线程完成资源释放；会话清理和诊断写入放到后台线程。
- 诊断文件名包含模式、时间与毫秒；保留最近连接的机内应用信息，并包含队列错误与最近一次应用崩溃堆栈。
- 相机 HTTP 请求禁用连接复用，缩略图限为单并发；只读文件下载遇到 I/O 中断最多尝试三次，每次从头写入独立的待完成文件。
- 正确读取 API 1.0 的 currentFNumber / currentShutterSpeed 等事件字段，未开放控制的参数仅显示读数。
- 底栏调整为首页、相机、本地、设置；相机页按当前连接模式呈现遥控或文件浏览，未连接时可直接选择模式。
- 本地图库支持移除导入记录；刷新和返回前台时清理文件缺失、已进回收站或长度不符的记录，避免历史记录阻止重新导入。移除记录不删除照片文件。

## 当前限制

- 遥控能力取决于机内应用与拍摄模式，未开放的控制不会由手机端补出。
- RAW 为实验模块，必须使用已登记的接收端 GUID；可通过设置内实验性 USB OTG 工具登记，也可填写电脑已登记的 GUID。
- 队列支持进程重启后恢复；需要重新连接同一相机并确认当前文件。重试从头下载，不支持字节断点续传。身份不明的历史任务不会自动关联。
- RAW 取消可能关闭 PTP 会话，需要在机身退出并重新进入 Send to Computer。
- RAW/JPEG 只做同来源 / 目录 / 文件主名的轻量关联，不做内容分析或跨模式自动合并。
- 本地图库管理本应用导入文件和记录；支持删除文件及仅清除记录，目录整理尚未实现。
- 间隔拍摄需保持应用前台；前台服务仅负责文件传输。
- B 门、曝光包围、直方图、峰值与 LUT 尚未实现。
- 从旧临时 Debug 签名切换到固定签名需卸载一次；后续固定签名版本可覆盖更新。

完整支持状态见 [SUPPORT.md](SUPPORT.md)，验证步骤见 [DEVICE_TEST.md](DEVICE_TEST.md)。
