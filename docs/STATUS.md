## 当前限制

- Smart Remote Embedded 可能只开放部分控制，曝光、对焦和录像能力取决于机内应用与当前模式。
- RAW 为实验模块，必须使用已登记的接收端 GUID；Android USB OTG 登记尚未实现。
- 下载记录会保留，传输队列尚不支持进程重启后恢复；取消或失败后重试从头下载。
- RAW 取消可能关闭 PTP 会话，需要在机身退出并重新进入 Send to Computer。
- RAW/JPEG 按文件名主干配对，跨日期重复编号可能误配。
- 本地图库管理本应用导入记录；完整删除和目录整理尚未实现。
- 间隔拍摄需保持应用前台；前台服务仅负责文件传输。
- B 门、曝光包围、直方图、峰值与 LUT 尚未实现。
- Debug 签名随构建环境变化，跨环境安装可能需要先卸载旧预览版。
