# 版本状态与限制

当前版本：`0.1.9-preview`（`versionCode 10`）。
适用环境：Sony α7R II（ILCE-7RM2，固件 4.01），Android 10 及以上。

## 测试状态

- 自动化测试与构建：
  - JVM 单元测试：96 项通过，0 失败 / 错误 / 跳过。
  - Android 运行时测试：15 项通过，0 失败 / 错误 / 跳过。
  - Android Lint：0 错误、33 警告；固定签名 APK 构建与证书指纹校验通过。
- 实机测试：
  - 遥控拍摄与传统 JPEG 传图（Send to Smartphone）主流程已在 α7R II 上实测可用，无明显问题（属总体测试结果，不代表每个子项边界已逐一覆盖）。
  - 当前测试机返回的 Smart Remote 接口为 API 1.0，曝光参数仅开放 EV，未开放 ISO、光圈、快门速度和录像控制。
  - `0.1.9-preview` 新增的页面导航与全屏沉浸式拍摄界面待实机测试。
  - RAW / 原文件传输（Send to Computer）和 USB OTG 登记接收端待实机测试。

## 已知限制

- 遥控能调哪些参数取决于机内 Smart Remote 版本和当前机身档位，未开放的接口手机端只能显示读数或禁用。
- RAW 传输和 USB OTG 登记属于实验功能。向相机登记新 GUID 会覆盖相机原本绑定的电脑接收端；RAW 模式下取消传输可能会关闭 PTP 会话，需要在机身上退出并重进“发送到电脑”。
- 未完成队列的保存和重连恢复针对相机图库文件导入（需重新核对当前目录后从头下载，不支持字节断点续传）；遥控拍照回传预览图暂不支持在界面手动重试恢复，相机身份不明时也不会自动关联旧队列。
- 相机图库和本地图库里的 `.ARW` 只显示缩略预览或同目录同名 JPEG，应用内没有内置 RAW 解码器。
- 间隔拍摄需要应用保持在前台，后台前台服务只负责文件下载。
- B 门、包围曝光、直方图、峰值对焦和 LUT 还没做。

各功能细项见 [SUPPORT.md](SUPPORT.md)，实机操作方法见 [DEVICE_TEST.md](DEVICE_TEST.md)。
