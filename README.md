# Sony Alpha Companion

Personal-use Android client for Sony α7R II (ILCE-7RM2).

Active development: [`feat/a7r2-android-client`](https://github.com/ayatinene/Sony-Alpha-Companion/tree/feat/a7r2-android-client).

The development branch contains the Android project, protocol research, build workflow, and hardware testing guide. Camera hardware validation is still pending.
